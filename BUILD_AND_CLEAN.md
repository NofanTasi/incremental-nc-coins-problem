# building and cleaning

## `haskell`

### build

```bash
$ cd sh/haskell
$ ./build.sh
```

an executable is generated in `bin/run/haskell`

### clean

```bash
$ cd sh/haskell
$ ./clean.sh
$ cd ..
```

the executable in `bin/run/haskell` is removed
